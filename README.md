# Portfólio — Felipe Larré

Site de portfólio pessoal (desenvolvedor front-end / UI/UX). Site estático: HTML + CSS + JavaScript vanilla, sem build.

## Estrutura

```
.
├── index.html          Página única (one-page)
├── css/style.css       Estilos, temas dark/light, responsivo
├── js/script.js        Dados dos projetos/skills + interações (typing, particles, tema, form)
└── assets/images/      Screenshots dos projetos e foto de perfil
```

## Rodar localmente

Abra `index.html` no navegador, ou sirva a pasta:

```bash
npx serve .
```

## Deploy

Publicado na Netlify a partir da branch `main` (diretório de publicação: raiz do projeto).
